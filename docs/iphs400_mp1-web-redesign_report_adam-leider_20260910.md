Improvements made:

A number of significant improvements were made to the course website. In terms of bug fixes and tech specs, the auth system was deleted (it relied on the removed netlify backend). The CSS bug hiding the "pending" banner on 13 of the week pages was fixed, and duplicated content across pages was specified and centralized. Dead CSS from an unused legacy header style was removed, and two metadata fields from the site's week-tracking file were stripped as the code never actually read them. I also added accessibility improvements sitewide: a keyboard skip-link, aria-current markers on the active nav item, and meta descriptions on every page. I added regression tests so these bugs can't quietly come back. One of my first tests was actually too broad, flagging the word "Netlify" anywhere on the site, which broke on a legitimate mention elsewhere, so I fixed the test to be more specific.

For the site design and layout, I restructured the helpful links to be more professional, well-organized, understandable, and accessible. The about and policies sections, less necessary and useful for students visiting the site, were moved to a footer, while the others remained on top in the header. Assignments was renamed to "Project Overviews", as that is the primary purpose of that section of the site. The weights table was removed from that page so that it could be centralized in the syllabus section, allowing the Project Overview page to focus on projects, and letting the weight of each project relative to the overall grade live in the syllabus section instead. The course details (professor name, location, class time, office hours) were moved into a permanent box header on the top right of every page, so that information is always easily accessible and visually present. I fully redesigned the homepage, getting rid of the quick links as they already exist easily in the header and footer, which are both now easy to see as the home page is now significantly shorter so one doesn't have to scroll to the bottom or the top. The schedule blurb with relevant dates was reorganized into a table for easy visual understanding on the schedule page. I also added a progress bar which updates each week, visible under the header at the top of the page, edited for aesthetics. The links to pending weeks that we have not yet reached have been rendered inaccessible until they go live. One of the most visually pleasing changes I made was the addition of a toggle-on dark mode. Users can choose between light and dark visual modes on the site. Last, I added minimal SVG icons sitewide (course mascot in header, nav icons, widget icons, section icons) matching the site's existing black/white/accent palette and the overall vibe of the course.
